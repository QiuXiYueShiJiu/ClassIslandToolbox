# 教学助手

> **v3 起不再有「拍照幸运抽签」**，包体从 4.6 MB 降到几十 KB；换来的是一个**屏幕批注**功能。

> ClassIsland 插件 ｜ 常驻屏幕最顶层的快捷工具条

一个写着「教学助手」的主按钮，点一下**向两边展开**：**幸运抽签** · 外加你自己加的任意条快捷方式。

**展开后主按钮居中，功能在两侧均分**——个数是奇数时右边多一个。
主按钮始终是视觉重心，展开的瞬间它不会跳，鼠标也正好还停在上面。

## 外观：云朵 + 天空

整个工具条是**一小片天**：下面半截是一片薄薄的蓝天（**不放装饰云**，只留天空渐变），
**每一颗按钮本身就是一朵云**，一半落在天上、一半悬空——像云飘在天际线上。
**正中间的主按钮是两朵云叠在一起**（一片左下、一片右上），
「教学助手」四个字**分压在两朵云上**——上面那朵两个字、下面那朵两个字，顺着两朵云的走向读下来。

- **主按钮那个"框"就是云的大小**：云把框填满，窗口按框算尺寸，所以整朵云都在窗口里
  （之前云比框大 1.34 倍、画在框外，多出来的那圈被窗口边缘切平，看着就是"主按钮被截断"）。
- **背景板只有主按钮的一半高，而且贴着底边。** 于是按钮的中心正好压在天际线上，上下各露一半。
  这样既像云飘在天上，**遮住底下的课件也少得多**——背景板矮了、整体也比原来矮了三分之一。
- 悬空比例是**算出来的不是凑出来的**：板高 = 主按钮直径的一半，按钮纵向居中，
  两者一减正好各占一半；所以改尺寸档位时这个比例不会跑掉。

- **天空、云、云朵按钮的轮廓全是矢量画出来的**，不依赖任何图片资源，任何尺寸都不糊。
- 云由几个相互重叠的椭圆拼成（画云最省事的办法：几个圆高低错开，轮廓自然就蓬松了）。
- 云**必须裁在圆角里**，所以整块绘制套在 `PushClip(RoundedRect)` 里——靠外层的 `ClipToBounds` 裁不出圆角。
- **按钮的云朵轮廓**由 `CloudButtonSurface` 算出来：Avalonia 的 `Geometry.Combine` 第二个参数写死成
  `RectangleGeometry`，两个椭圆并不起来，所以改用**射线法**——以质心向四周打一圈射线，
  每条取「和所有椭圆交点的最远值」，连起来就是并集外边界。这样得到的是**一条闭合路径**，
  能填充也能描边（用一堆椭圆直接画的话，填充看不出来，描边会把每个圆的内部弧线也画出来）。
- 文字用带蓝的深灰而不是纯灰：压在淡蓝底上，纯灰会显脏。

配色是固定的，不跟应用主题色走。悬浮条常驻在桌面和课件上面，浅色比深色更不容易压住底下的内容。

```
   收起：            ( 教学 / 助手 )

                       ┌────────────────────────────────────────────────────────┐
   展开：              │  🌐 浏览器  📝 记事本  ( 教学/助手 )  🖥 关机  📁 课件 │
                       └────────────────────────────────────────────────────────┘
                         └──── 左侧 2 个 ────┘         └──── 右侧 3 个 ────┘
```

## 怎么用

| 操作 | 效果 |
|---|---|
| **左键点主按钮** | 展开 / 收起工具条 |
| **左键按住拖** | 挪位置（拖不出屏幕，可以压住任务栏） |
| **展开后点某一条** | 执行那一条 |
| **右键 / 触摸长按** | 设置菜单 |

- **只有点主按钮才会收**：用快捷方式、指针移开、去别的地方点、闲置多久，工具条都原地待着，
  直到你再点一下主按钮。
- 点完一条快捷方式后默认也会收起，可在设置页关掉。
- 位置、大小、各项开关都会自动记住。

## 幸运抽签

> **可以整个关掉。** 设置页最上面有一个「**启用幸运抽签**」开关。关掉之后工具条上不再出现「幸运抽签」，
> 右键菜单里相关的几项也会隐藏，设置页里下面整块幸运抽签与拍照配置都会收起来——
> 只想要一个纯快捷方式工具条的话就关掉它。
> **名单和幸运抽签次数历史都会原样保留**，重新打开就能接着用。

抽取规则：

| 方式 | 行为 |
|---|---|
| **名单幸运抽签** | 从纯文本名单里抽一个名字 |
| **拍照幸运抽签** | 拍一张合影，从检测到的人脸里随机挑一个，裁出人像 |

抽中的结果会在屏幕中央弹出大字，可选同时往 ClassIsland 主界面推一条提醒。

### 名单幸运抽签是「均衡抽选」，不是纯随机

纯随机做不到公平：30 个人每次独立随机抽 30 次，平均会有 **11 个人一次都没抽到**，
而有的人已经被抽了三四次。所以这里用的是**带次数历史的轮转抽选**，两条规则：

1. **先保轮次**——本轮抽过的人不再进候选，一轮之内每人恰好抽到一次。
   所以不会有人在别人还没轮到之前被抽第二次，也不会有人被跳过。
2. **再按次数排**——候选里只留累计次数最少的那一档，再等概率随机取一个。
   名单中途加进来的人、被手动「开始新一轮」打乱过进度的人，都会在这一层被优先补上。

**因为一轮必定抽完，工具条上不显示「还剩几人」这种进度**——它只会一路走到 0，没有信息量。
想看的话在右键菜单的标题上（第几轮 / 共几人）和统计窗口里都有。

最后那一下永远是**在候选里等概率随机取一个**：走操作系统熵源、不带种子、
不按名单顺序、不用姓名做 tie-break。每轮顺序都是重新掷的，不是固定轮转。

**每一轮的第一抽会回避最近点过的人**（默认 1 个，可调 0~5），
保证「上一轮最后一个」不会立刻变成「新一轮第一个」。
它只影响顺序不影响次数，被回避的人本轮照样会被抽到。

### 看统计

**右键工具条 → 查看幸运抽签次数（饼状图）**，设置页里也有入口。

窗口里是一张饼图（每块一个人，面积 = 被抽次数占比）加一份**按次数排序**的明细表，
还标出每个人本轮是否已经抽过、整体是否已经均衡。窗口开着时会每 2 秒自刷。

### 名单

纯文本，一行一个名字，记事本就能改：

```
张三
李四
王五
```

空行和以 `///`、`#` 等常见注释符号开头的行会被忽略，重复的名字只算一个，**保存后立刻生效**。
位置：右键菜单 → 打开名单文件。

### 拍照幸运抽签

用的是 OpenCV Zoo 的 **YuNet**（232 KB ONNX），靠 ONNX Runtime 跑，两样都随插件打包，全程离线。

> ⚠ **只能检测正对镜头的人脸**，背对镜头的人抽不到。
> 建议先在设置页用「试拍一次」对着真实场景量一遍——它会打出分辨率、检出人数、各步耗时，
> 并把画了检测框的照片显示出来。

可调项：摄像头选择、保持开启时长（默认 120 秒，开着连着拍几乎是瞬时的）、
人脸分数阈值（默认 0.50）、分块检测、回避刚抽过的人、裁切范围、是否保存原图。

## 自定义快捷方式

**应用设置 → 置顶工具集 → 快捷方式**，可以加任意多条。
每一条在工具条上显示为「**图标 + 名称**」，名称最多显示 6 个字。

| 类型 | 表单长什么样 |
|---|---|
| **启动程序 / 命令** | 程序路径 + `浏览…` 按钮；额外有命令行参数、管理员运行 |
| **打开网址** | 网址输入框 |
| **打开文件或文件夹** | 路径 + `选文件` / `选文件夹` 两个按钮 |
| **ClassIsland 地址** | 地址输入框 + 常用地址下拉 |

**表单会跟着类型变**——选「启动程序」才会出现参数和管理员选项，
选「打开文件或文件夹」才会出现两个选择按钮。

### 图标：默认就是文件本来的图标

指向真实文件的快捷方式（**启动程序** 和 **打开文件或文件夹**），
按钮上显示的是**系统资源管理器里那个图标**——选了 `chrome.exe` 就是 Chrome 的图标，
选了某个 `.pptx` 就是 PowerPoint 的图标。

- 实现走系统的 `SHGetFileInfo`，取出图标位图直接贴到按钮上，**只在 Windows 上生效**。
- 取不到时（文件不在、不是 Windows）自动退回下一档。
- 不想要文件图标，可以在设置页把「**使用文件本身的图标**」取消勾选。

退回顺序是：**文件本身的图标 → 你填的图标 → 该类型的默认图标**。

「图标」框里可以填一个 **emoji**，也可以填**一个汉字**（比如「投」「网」）——
汉字任何中文字体都能渲染，是 emoji 字体缺失时的稳妥选择。
右边的小下拉框可以从 16 个常用图标里直接挑一个。
留空则按类型给默认值：🖥 程序 / 🌐 网址 / 📁 文件 / 🏝 ClassIsland。

### 打开快捷方式时

点下任意一条，**快捷方式那一块**会换成一条提示，**主按钮原样留在正中间**：

```
   浏览器 正在打开   （ 教学 / 助手 ）   请稍后…
   └── 原先按钮的位置 ──┘   ↑ 主按钮没动   └── 原先按钮的位置 ──┘
```

- 提示分左右两条，分别盖在原先两组按钮的位置上，都往中间靠，读起来连成一句。
- 外部程序起来时工具条不会压在它上面。
- 打开失败会换成暖红提示并多停留一会儿（比如「找不到这个程序」），不会静默失败。
- 提示消失后快捷方式按钮自己回来；**工具条不会因此收起**。

### 悬浮窗透明度

设置页有一条滑动条（**30%~100%**）。讲课时工具条压在课件上，有时候会挡住关键内容——
调低一点能透过去看见底下，又不像「隐藏」那样找不回来。

作用在**根内容**上而不是 `Window.Opacity`：后者依赖平台的窗口合成，有的环境下会整个失效；
作用在内容上就是普通的渲染期 alpha，各处表现一致。

### 调整顺序：预览 + 直接拖

预览里的天和按钮都是按当前尺寸画的，改「大小」它会立刻跟着变。

设置页里有一块**顺序预览**，排布和工具条一模一样（左一半 · 主按钮 · 右一半，奇数时右边多一个）。
**按住任意一颗往左右拖就能换位置**，预览和工具条同时跟着变，不用「先改再应用」。

- 「幸运抽签」固定在按钮里，不参与排序，拖不动。
- 拖到一半会重画预览，所以指针捕获挂在**不会动的那一行**上——挂在按钮自己身上的话，
  控件一被重建捕获就丢了，拖到第二格就断。
- 习惯用按钮的话，每一行右边的「上移 / 下移」也还在。

### 两条安全选项

- **管理员运行**（仅「启动程序」）：用 `runas` 启动，会弹 UAC。
- **需要确认**：勾上之后**要点两次才执行**。第一次点击按钮变红显示「再点一次」，
  5 秒内不点第二次就自动取消。工具条常驻桌面很容易误触，给「关机」这类危险操作勾上会安全很多。

### 常用示例

设置页里有个「添加常用示例」，一键加上浏览器、记事本、计算器、截图、ClassIsland 设置、档案。

几个可用的 ClassIsland 地址（写错了不会报错，只会没反应）：

| 地址 | 效果 |
|---|---|
| `classisland://app/settings` | 打开应用设置 |
| `classisland://app/profile` | 打开档案设置 |
| `classisland://app/edit` | 进入主界面编辑模式 |
| `classisland://app/test` | 导航测试窗口 |

## 为什么不「鬼畜」

悬浮工具条最怕的是「点一下，整排东西乱跳 / 窗口自己跑了」。这里用五件事把它按住：

1. **按钮宽度在建的时候就量死。** 点「需要确认」的按钮时，标题会从「关机」变成「再点一次」，
   如果宽度跟着内容走，整条工具条会当场重排——主按钮和旁边所有按钮一起平移。
   所以宽度按「正式标题」和「再点一次」里**更宽的那个**算，一次算好，之后不再变。
2. **展开动画不碰布局。** 只做透明度和 `translate`（只影响绘制，不影响排布）。
3. **尺寸和位置在同一帧里定下来。** 展开时先强制跑一次布局拿到真实宽度，
   紧接着就把窗口摆正。否则中间会有一帧是「新尺寸 + 旧位置」，
   在触摸屏或低帧率机器上就是肉眼可见的一跳。
4. **拖动和点击的判定只做一次，永不翻案。** 见下一节。

### 拖动 vs 点击：怎么才能不互相误触发

这两件事共用「按住主按钮」同一个动作，所以判定必须干脆。三条：

1. **一次性判定。** 位移跨过阈值就是拖动，没跨过就是点击——**跨过之后不会再退回**。
   距离阈值一过，意图已经明确了；再去翻案只会制造「想拖却变成了点」。
2. **阈值按输入设备分开，而且给得够宽。** 鼠标 **8 px**、触摸 **28 px**。
   触摸屏上「点一下」从来不是零位移，手指按下去、抬起来中间会漂 5~20 px；
   阈值按鼠标那套来，绝大多数点击都会被判成拖动。
3. **起步不跳格。** 跨过阈值的那一帧**不按绝对定位直接跟过去**（那会让窗口「啪」地跳一个阈值那么远），
   而是扣掉阈值、只走超出的部分：手指走 14 px，窗口就走 6 px。
   顺手重新对一次基准，后续跟手拖动照常；单次大位移事件（触摸驱动常把多个 move 合并成一个）
   也不会丢位移。

另外，位移超过 9 px 就取消「长按弹菜单」——手指按下之后犹豫、轻微挪动，
不该在 450 ms 后突然弹出一个菜单。

> 一路上修掉的几个真问题，可以串成一条线：
> **① 纵向锚点算错**（展开时把左侧按钮组的宽度也加到了 Y 上，整条往上跳一百多像素）；
> **② 触摸抖动被当成拖动**（阈值太小）；
> **③ 拖动完不更新锚点**（展开状态下拖完，一收起就弹回原处）；
> **④ 拖动判定被翻案**（松手后又按总位移改判成点击）。
>
> 它们当初都没被测出来——测试只断言了 X 坐标、只用鼠标事件驱动、
> 也没覆盖「展开状态下拖动」。现在会同时断言 X 和 Y，用无头输入真的模拟
> 「按下—抖动—抬起」和「按下—拖走—抬起」，并专门盯着上面这四条。

## 置顶是怎么做到的

工具条会被持续按在最顶层，除了设 `Topmost`，还会：

- 加上 `WS_EX_TOOLWINDOW`（不进 Alt+Tab）和 `WS_EX_NOACTIVATE`（不抢焦点，
  这样点它不会把用户正在用的窗口弄失焦）；
- 用秒级定时器反复调用 `SetWindowPos(HWND_TOPMOST)` 顶回去——
  全屏应用、别的置顶窗口、资源管理器重启都会把窗口挤下去；
- 置顶由定时器持续维持，不做置顶复位的窗口不会跟它互相抢导致画面闪。

全是文档化的公开 API，不改系统设置，也不碰别的进程。非 Windows 平台只靠 Avalonia 自己的 `Topmost`。

## 数据存放

插件配置目录（设置页上有完整路径）：

| 文件 | 内容 |
|---|---|
| `settings.json` | 全部设置和快捷方式 |
| `名单.txt` | 幸运抽签名单 |
| `幸运抽签统计.json` | 累计被抽次数、轮次 |

`幸运抽签统计.json` 和 `settings.json` **分开存**：改设置、重装插件都不会把幸运抽签历史带走。
写盘是「先写临时文件再原子替换」，抽到一半断电也不会把文件截成半截 JSON。

## 从源码构建

```bash
# 方式一：放进 ClassIsland 源码树的 plugins/ 目录下
dotnet build -c Release

# 方式二：独立构建并打包（在 dist/ 下产出 .cipx）
./pack.sh
```

独立构建时会自动从 NuGet 取 `ClassIsland.Core` 2.1.0（对齐宿主那一版），
放进源码树时则改用同级的 `ProjectReference`。

把 `dist/` 下的 `.cipx` 拖进 ClassIsland 的【应用设置】→【插件】页面即可安装。

## 屏幕批注

工具条上有**两颗独立按钮**：**✏️ 批注**（软笔）和 **🧼 橡皮**。
想擦就直接点橡皮，不用先进菜单换工具。

```
点「批注」一次：开启。画面压暗，红色软笔，直接就能写
点「批注」再点：配置栏打开（六色 + ✖ 退出）
点「批注」再点：配置栏收起            ← 同一颗按钮就是配置栏的开关键
点「橡皮」    ：切到橡皮，配置栏保持打开（六色 → 三档 + 清屏 + 退出）
点「✖ 退出」  ：退出批注。**画留在屏幕上**，鼠标和触屏还给系统
```

- **正在生效的那颗按钮会变暗**（批注或橡皮），一眼能看出现在是哪个工具在工作。
  屏幕本身**完全透明**——批注是"直接在屏幕上写"，盖一层暗色会把课件一并压灰。
- **退出不清屏**：点「✖ 退出」之后画**留在屏幕上**，只是覆盖层变成"点击穿透"，
  鼠标和触屏能点到下面的程序了。想真的清掉画，用橡皮那一行的「清屏」。
  （覆盖层窗口不能关——画布是它的一部分，关掉等于把画一起丢了，再进来就是白纸。）
- **关掉批注只能走「✖ 退出」**，不走按钮的第三次点击：
  这样"关掉"是一个明确的动作，不会在开合配置栏的时候误触退出。
- **画在所有窗口之上**，包括课件、视频、浏览器。
- **颜色是画出来的实心圆，不是 emoji。** 颜色选择器最要紧的就是"颜色看得见"，
  而 🔴🟡 这类 emoji 依赖彩色字体——系统缺字时会变成黑白符号甚至一坨斜纹，按钮就完全失去意义了。
  橡皮同理：三个方块的大小直接对应擦除范围。
- **笔画存成点列，不存位图。** 橡皮要「擦掉一部分」，在位图上做就得处理混合模式
  （Avalonia 的 `BlendMode` 还在实验阶段），而按点删是纯几何运算；
  清屏这类操作也因此是常数时间。擦断一条线会分成两段——两头留着。
- 颜色只给六个（红黄绿蓝黑白），橡皮只给三档：批注是课堂上随手用的，
  选项一多就变成"挑颜色"而不是"讲题"。
- **触摸屏适配**：只认第一根手指——手掌擦过、扶屏幕搭上的第二根不会把笔画搅乱；
  指针捕获被系统收走（切窗口、被别的程序抢走）时会自动收笔，
  不这样的话之后就**再也画不出东西**，看着像"批注突然失灵"。
- **笔迹是平滑曲线**，不是折线：以相邻两点的中点为端点、原始点当控制点画二次贝塞尔，
  计算量和连直线差不多，快速划动时却顺得多。
- **画完的笔画会缓存路径**：以前每一帧都要把屏幕上所有点重新拼一遍，
  攒到几百个点就开始卡；现在只有正在画的那一条每帧重算。
