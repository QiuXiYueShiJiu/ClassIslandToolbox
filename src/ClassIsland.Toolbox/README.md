# 教学助手

ClassIsland 置顶工具条插件：幸运抽签、屏幕批注、自定义快捷方式。

常驻屏幕最顶层，一个云朵圆钮点开向两边展开。

---

## 怎么用

左键点云钮展开或收起，按住拖动挪位置，右键出菜单。除了点主按钮和点具体功能，它不会自己收起来；讲课时手滑碰到屏幕，不会莫名其妙缩回去。

| 想做的事 | 去哪 |
|---|---|
| 加功能、调大小透明度、排顺序 | 应用设置 → 教学助手 |
| 改名单 | 设置页里点「打开」，改完保存即生效 |
| 看抽签次数 | 设置页里点「查看饼状图」 |

---

## 幸运抽签

按名单抽人，两层约束，顺序不能反：

1. **先保轮次** —— 一轮之内每人恰好被抽到一次，抽完才开新一轮；
2. **再按次数排** —— 只在累计被抽次数最少的那一档人里抽。

最后一步用系统熵源等概率取一个，不带种子、不按名单顺序。另有「新一轮开头回避」，避免上一轮最后一个立刻又成了新一轮第一个。

抽到的人会亮在屏幕中央的一朵云上，停留几秒后自己淡出。次数历史存在插件配置目录，换名单、改设置、重启 ClassIsland 都不影响它，右键就能看占比饼图。

**名单是一个纯文本文件，一行一个名字。** 空行、以及以 `///` 或 `#` 或 `//` 或 `;` 等常见注释符号开头的行会被忽略，重复的名字只算一个 —— 从别处拷一份名单过来不用先清理格式。

## 屏幕批注

画在所有窗口之上，包括课件和视频。

- **软笔** 六色，三档粗细，笔迹是平滑曲线不是折线
- **荧光笔** 半透明，专门用来划重点，永远画在软笔下面 —— 先划重点再在上面写字，字不会被糊掉
- **橡皮** 三档，按点擦除，一条线被擦中间会断成两段
- **激光笔** 只留一条会自己消失的轨迹，不在屏幕上留下任何东西
- **撤销 / 重做** 六十步历史；橡皮整段手势算一步，清屏也能撤回来

**退出批注不会清屏。** 画留在屏幕上，鼠标和触屏还给系统，能直接点到下面的课件继续讲。想清掉用「清屏」。

## 自定义快捷方式

想放什么放什么，图标＋名称显示在工具条上。四类：

- **启动程序 / 命令** —— 可带命令行参数，可勾选管理员运行
- **打开网址** —— 用默认浏览器打开
- **打开文件或文件夹** —— 见下方三种路径方式
- **ClassIsland 地址** —— 直接跳到应用设置、档案设置、主界面编辑模式

### 「打开文件」的三种定位方式

| 方式 | 存什么 | 适合 |
|---|---|---|
| 绝对路径 | `D:\课件\第一课.pptx` | 最直接，换机器要重填 |
| 相对路径（CI 内） | `课件\第一课.pptx` | 相对 ClassIsland 数据根目录，整个目录搬走还能找到 |
| 插件内部副本 | `第一课.pptx` | 文件复制进插件自己的目录，原文件放哪都不影响 |

内部副本只收**视频 / 图片 / Office 单文件**。保存是幂等的：同样内容重复点不会越存越多；同名但内容不同会另存成 `名字-2.ext`，不覆盖已有的那份。设置页里还有「清理未使用的副本」，删掉快捷方式之后能把空间收回来。

指向文件的按钮**默认直接显示文件本身的图标**（走系统资源管理器那一套），也可以自己填 emoji。

## 环境要求

- **ClassIsland 2.0.0.1 ~ 2.1.x**（API 版本 `2.0.0.0`）
- Windows 完整支持；Linux 可用；macOS 代码路径齐全但未实机验证
